# Time-of-Flight Pose Landmarker Estimation

A pose landmark estimation model trained for grayscale images captured by ToF (Time-of-Flight) cameras.

## Project Overview

### Data Capture

For this project, we would use a ToF camera (from Arducam) and an RGB camera (webcam) at the same time to capture both RGB frames and depth frames.

Before we start to collect data, we need to calibrate the webcam and the ToF camera by using an ArUco (in this code example is tag [`#77 6X6_250`](https://github.com/ocoke/tof-pose-landmarker/blob/main/aruco_marker_77_calibration.png)) tag. The user would need to capture as many frames as possible with the tag in different positions of the frame to accurately calibrate the two cameras.

For data collection, in the room, there would be a person standing in front of the camera.
The code example will apply the calibration results directly so that the annotations from the RGB camera generated by Mediapipe can be directly applied to the depth frames.

To use the ArUco marker for calibration, parts of the ArUco marker would be covered with retroreflective tape to reflect the infrared light emitted by the ToF camera, and this would ideally make parts of the marker brighter in the ToF frame.

The image from the RGB camera would be passed into the Mediapipe Pose Landmarker model to get the annotations for the RGB frames. 
The annotations would be applied to the depth frames to get the training datasets for the Time-of-Flight pose landmarker estimation model.
